# Upstream source

> Legacy `tools/tts` scripts mentioned here were removed on 2026-10-20. Retrieve historical scripts from Git revision `e591c94`; their paths below describe provenance or historical reproduction, not current executable entry points.

Model equations, message formats and generation schedules are ported from:

- https://github.com/OpenMOSS/MOSS-TTS at revision
  `934d6826b084c46a0d033402174d5f8ac4ed2519`.
- https://github.com/OpenMOSS/MOSS-Audio-Tokenizer at revision
  `8c50ac4c5d7287d2ed6ea20a08c90ca439887d23`.

Both upstream codebases use Apache-2.0; LICENSE and NOTICE are retained.
This crate contains native Rust inference, not upstream CLI/server/training
programs. Model resources are pinned in assets and downloaded separately.
Local adaptations originated in TRNovel; see the root SOURCE.md.

Nano GPT2 and stereo codec support were carried from TRNovel experiment
`8be7d953fd91433569767404e5a7a37534956d5b`. Equations and prompt formats
follow OpenMOSS/MOSS-TTS-Nano checkpoint `44502f80dbf9743528fa921cc544d662c685ebec`;
attention conventions were cross-checked against Apache-2.0 community source
https://github.com/ramishi/moss-tts-nano-rust-candle at
`f4d3fcf4de9b4118ee664087f88495f4174836e1`. No gated weights are included.

The retained `realtime-previous-turn.json` records a retired multi-turn
experiment; current synthesis does not use it as an acceptance gate.
Single-turn prompt rows are checked against the fixed official
`make_ensemble` and pre-inference `prefill` AST using the actual fixed
tokenizer: no reference / twenty reference frames and 3/12/16 text tokens.
`tools/tts/moss_realtime_prompt_oracle.py` regenerates this six-case fixture
without model weights, recording source and tokenizer SHA-256 identities.
The generator uses this tested prompt builder. Reserved tokens, premature
EOS, frame exhaustion and cancellation remain errors, not completion.

### VoiceGenerator no-reference prompt fixture (2026-11-11)

`tests/fixtures/voicedesign-official-prompt.json` is generated by
`tools/tts/moss_voicedesign_prompt_oracle.py` from the fixed repository commit
above, VoiceGenerator revision `97521ec2b6f3ec5026ac1f5751f8fc302d82c2d4`,
its tokenizer and `chat_template.jinja`; the fixture records source digests.
The script extracts the official processor methods and normalizer and requires
no model weights. Supply their local paths and `--output` to reproduce it.
The checkpoint's chat template must be provided explicitly when the local
snapshot does not include it.

The ignored `compare_official_no_reference_prompt` test requires
`MOSS_VOICEDESIGN_DIR` pointing at the pinned model snapshot. It is a strict
comparison. The initial run failed all four cases because local prompts appended
an audio-start row and skipped official text normalization. Both differences
were corrected on 2026-11-11: all four complete prompt rows now match.
`tools/tts/moss_voicedesign_normalize_oracle.py` independently executes the fixed
normalizer (SHA-256 `b7c1fab4fd7bdc8c779df99f6af310fd8cd0746b759db684bf147e0c182b3183`);
61 upstream/public/Unicode normalization cases match the native port.
The fixture and native C-category classification are fixed to Unicode 13 below.
These input gates do not replace real-model generation or acoustic listening.

### Unicode 13 category data

The VoiceGenerator reference fixture uses Python 3.9.6 and Unicode 13.0.0.
`src/prompt/normalize/unicode13.rs` is generated from its `unicodedata` C
categories (Cc, Cf, Cs, Co and Cn), including unassigned code points. The
independent check parses the official
[UnicodeData.txt](https://www.unicode.org/Public/13.0.0/ucd/UnicodeData.txt)
(SHA-256 `bdbffbbfc8ad4d3a6d01b5891510458f3d36f7170422af4ea2bed3211a73e8bb`)
and verifies all 1,114,112 code points against Python's database, including
surrogates. The 679 sorted inclusive ranges have SHA-256
`b7b496d81187f0ac55ee53a03777aacbccf95665db65fc78c912da06e9da946c`.
Regenerate or verify with Python 3.9 and
`tools/tts/moss_unicode13_other_ranges.py UNICODE_DATA [--check]`.

Unicode's [13.0 UCD readme](https://www.unicode.org/Public/13.0.0/ucd/ReadMe.txt)
identifies the version and links its terms. The current official
[Unicode license](https://www.unicode.org/license.txt) is retained at
`assets/unicode-13/LICENSE.txt` (SHA-256
`e7a93b009565cfce55919a381437ac4db883e9da2126fa28b91d12732bc53d96`).
The normalization oracle fixture has 61 cases; its new U+1FAE8 case records
Unicode 13's unassigned classification. Running the fixture after the native
lookup is wired is required to establish the new case passes.

### 2026-11-12 Metal VoiceGenerator validation

The adapter now loads the pinned VoiceGenerator checkpoint in BF16 on Metal,
as on CUDA. F16 produced invalid logits (five attempted cases); F32 was cancelled
during codec loading under memory pressure on this 24 GiB M4 Pro. These failed
experiments remain in the local validation evidence. BF16 completed all 19 public
inputs: 17 EOS/PCM outputs and two predeclared reference-design length rejections.
Artifacts: `.local/matrix-moss-design-bf16-full-v15/`; this is generation evidence,
not official acoustic numeric equivalence, CUDA acceptance or human listening.
