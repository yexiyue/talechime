# Spec Delta

## Purpose

模型无关的音色资产管理：音色的存储、生命周期、单文件搬运与跨模型物化，使同一音色可被任意支持克隆的合成模型使用，宿主无需理解后端差异。

## ADDED Requirements

### Requirement: 音色资产独立存储

音色库 SHALL 将每条音色保存为独立记录，内容至少包含：标识、显示名、参考 WAV 原始字节、准确转写、可选设计描述与来源标注。记录 SHALL 存放在用户数据目录（`~/.talechime/voices/`）下，与模型资源目录分离；参考 WAV MUST 原样保留，不因任何模型消费而被替换或删除。

#### Scenario: 设计产出进入音色库
- **WHEN** 一次音色设计完成后
- **THEN** 音色库中新增一条记录，包含生成的参考 WAV、试音文本转写、设计描述与引擎来源标注

#### Scenario: 参考录音跨后端保持原始
- **WHEN** 某音色被多个合成模型物化消费后
- **THEN** 音色库中的参考 WAV 字节与最初保存时完全一致

### Requirement: 音色标识规则

音色 id SHALL 由 1..64 个 ASCII 字母、数字、`-` 或 `_` 组成，MUST NOT 与库内已有音色冲突。用户省略 id 时系统 SHALL 自动生成不冲突的短 slug；指定冲突 id 时 MUST 明确报错且不覆盖已有记录。

#### Scenario: 省略 id 自动生成
- **WHEN** 导入或设计音色时未提供 id
- **THEN** 系统生成唯一短 slug 并返回给调用方

#### Scenario: id 冲突拒绝
- **WHEN** 以库内已存在的 id 创建音色
- **THEN** 操作失败并提示已存在，原记录保持不变

### Requirement: 音色生命周期管理

系统 SHALL 支持列出库内全部音色（含显示名与来源）、重命名显示名、按 id 删除；删除 MUST 原子移除该音色的库记录，且不触碰任何模型侧缓存之外的用户数据。

#### Scenario: 删除后清单同步
- **WHEN** 删除某音色后列出音色
- **THEN** 该 id 不再出现，其余音色不受影响

### Requirement: 单文件导出与导入

系统 SHALL 将单个音色导出为一个自包含文件（WAV + 转写 + 描述 + 来源元数据），并 SHALL 能从该文件导入为新音色（可指定新 id）。导出/导入 MUST 在不同机器间可搬运。

#### Scenario: 导出后异地导入可用
- **WHEN** 在机器 A 导出音色文件，复制到机器 B 导入
- **THEN** 机器 B 的音色库出现该音色，且可立即用于合成

### Requirement: 跨模型物化

系统 SHALL 能将库音色物化到任意支持参考克隆的合成模型：参考音频按目标模型要求重采样，逐模型限制（时长上限等）MUST 在物化时校验并给出明确错误。物化产物 SHALL 视为可再生缓存，其缺失或损坏 MUST NOT 影响库记录，系统 SHALL 能随时重新物化。

#### Scenario: 一处设计多处使用
- **WHEN** 用引擎 A 设计的音色被选入与 A 无关的合成模型 B 朗读
- **THEN** 物化成功且合成使用该音色，无需重新设计

#### Scenario: 缓存丢失自动再生
- **WHEN** 某模型的物化缓存被删除后再次用该模型合成同一音色
- **THEN** 系统从库重新物化，合成正常进行

#### Scenario: 超出模型限制明确报错
- **WHEN** 物化一条时长超过目标模型上限的音色
- **THEN** 操作在合成开始前失败，错误指明限制

### Requirement: 合成入口接受库音色

Rust API 直接合成、计划 `SpeechSpan.voice` 与 CLI `--voice` SHALL 接受库音色 id 并在执行/会话启动时隐式物化；未知 id 或不可物化 MUST 产生明确错误。自动物化与显式物化 MUST 走同一条内部路径。

#### Scenario: 计划携带库音色 id
- **WHEN** 计划中的 span 以库音色 id 标注音色并启动会话
- **THEN** 该音色被物化到本次合成所用模型并用于朗读

#### Scenario: 未知音色报错
- **WHEN** 合成请求引用库中不存在的音色 id
- **THEN** 请求失败并提示该 id 不存在

### Requirement: 旧数据保持不动

系统 MUST NOT 扫描、迁移、转换或删除现有 per-model 音色目录；音色库初始化为空。旧目录中的自定义音色不再出现在库清单中。

#### Scenario: 升级后旧目录原样保留
- **WHEN** 新版本首次运行后
- **THEN** `<resources>/voices/` 下既有内容无任何改动，库清单为空

### Requirement: 协议与 CLI 的库音色面

JSON Lines 协议 SHALL 支持列出与删除库音色；CLI SHALL 提供模型无关的音色子命令（设计、导入、清单、重命名、删除、导出、导入包），且这些命令 MUST NOT 依赖当前选中的合成后端。

#### Scenario: CLI 音色命令不选后端可用
- **WHEN** 未指定 `--backend` 时执行音色清单或设计命令
- **THEN** 命令正常工作，输出不依赖任何合成模型选择
