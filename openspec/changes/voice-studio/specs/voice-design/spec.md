# Spec Delta

## Purpose

用文字描述设计音色的能力：设计引擎作为可插拔抽象，宿主可自动或显式选择引擎，产出进入音色库，全程可取消且不要求先准备合成模型。

## ADDED Requirements

### Requirement: 设计引擎抽象与清单

系统 SHALL 将每个可用的音色设计能力登记为引擎，并向宿主暴露清单：引擎标识、显示名、可用设备、资源代价（是否需要额外下载及规模）与就绪状态。新增引擎 MUST NOT 要求修改宿主侧流程。

#### Scenario: 枚举引擎含就绪状态
- **WHEN** 宿主查询设计引擎清单
- **THEN** 每个引擎报告其设备支持、资源代价与当前是否已就绪

### Requirement: 自动引擎选择

自动设计入口 SHALL 按默认策略选择引擎：优先复用已就绪主模型自带的描述能力（零额外下载），其次按设备可用性选择专用设计模型。宿主 MUST 能覆盖该选择。

#### Scenario: 已就绪模型被优先复用
- **WHEN** VoxCPM 模型已就绪且宿主调用自动设计
- **THEN** 设计由 VoxCPM 的描述能力完成，不发生额外模型下载

#### Scenario: 无就绪模型时选专用引擎
- **WHEN** 没有任何主模型就绪且设备支持某专用设计模型
- **THEN** 自动选择该专用引擎，下载进度对外可见

### Requirement: 显式设计请求

系统 SHALL 提供显式设计入口：指定引擎，并可覆盖试音文本、设备与 seed；未指定的参数取该引擎默认值。未知引擎或不可用设备 MUST 明确报错。

#### Scenario: 指定引擎与文本
- **WHEN** 宿主显式指定引擎并覆盖试音文本发起设计
- **THEN** 设计按指定参数完成，产出进入音色库

#### Scenario: 未知引擎报错
- **WHEN** 显式请求一个不存在的引擎
- **THEN** 请求失败并列出可用引擎

### Requirement: 设计产出契约

一次成功的设计 SHALL 产出一个完整生成的参考录音（含其试音文本转写与描述），保存为音色库音色并携带引擎来源标注；生成未实际完成时 MUST NOT 产出音色。

#### Scenario: 产物完整入库
- **WHEN** 设计成功完成
- **THEN** 库中新增音色，包含完整录音、转写、描述与引擎来源

### Requirement: 输入约束前置校验

设计请求的文本与描述限制（长度、字符集等按引擎声明）MUST 在加载模型权重之前校验；违反时立即报错且不触发下载。

#### Scenario: 空描述立即拒绝
- **WHEN** 提交空描述的设计请求
- **THEN** 请求被拒绝且未发生任何模型准备

### Requirement: 设计取消语义

设计任务 MUST 可取消：取消后停止计算、释放推理资源，且不产生部分结果入库。取消与完成竞态时结果 MUST 二选一且明确。

#### Scenario: 中途取消无残留
- **WHEN** 设计进行中宿主取消
- **THEN** 计算停止、GPU 权重释放、音色库无新增记录

### Requirement: 设计独立于合成模型

发起设计 MUST NOT 要求先准备或选择任何合成模型；设计引擎资源与合成模型资源相互独立。

#### Scenario: 无合成模型仍可设计
- **WHEN** 宿主尚未准备任何合成引擎时发起设计
- **THEN** 设计正常进行，仅准备所选设计引擎自身资源

### Requirement: 协议设计命令

JSON Lines v7 SHALL 新增加法式设计命令：请求携带名称、描述及可选的文本/引擎/设备/seed；引擎资源准备进度复用既有进度事件流；完成时 SHALL 发出携带音色 id 的新事件；失败走既有错误信封。

#### Scenario: 协议设计全流程
- **WHEN** 协议宿主发送设计命令
- **THEN** 先后收到资源进度事件与完成事件，完成事件携带可在计划中直接引用的音色 id
