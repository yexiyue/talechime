# Proposal

## Why

整篇小说单音色朗读需要稳定身份、剧情起伏和句间承接；目前滚动接续可能累积音色或语速偏差，固定锚点又可能让语气单调。历史《蛊真人》实验已有差异反馈，但不能替代当前主线的逐模型、整章试听确认。

## What Changes

- 建立可复现的单音色长篇朗读实验能力，以用户授权的 TRNovel 本地《蛊真人》为语料，保留原文摘要、UTF-8 范围和自然段结构。
- 分离接续策略与组段策略的对照，按模型比较固定原始参考、有限滚动接续、可用的身份与上下文双参考；不假定所有模型支持相同机制。
- 按短选段筛选、逐模型策略细化、整章耐久、复现四阶段推进，每阶段交付可试听产物并等待用户明确听感决定后推进依赖批次。
- 允许模型或策略被淘汰、仅适用于短文本或保持待验证；Nano 不因支持滚动接续而必须启用它。
- 复用现有 Rust 开发工具与原生 owner，记录参数、资源、实际分块、取消和失败证据；自动检查用于定位问题，不替代试听。
- 本变更交付实验工具和模型策略结论，不自动修改生产默认、稳定 API 或 JSON Lines v7。采纳实验胜出策略另行提案。

## Capabilities

### New Capabilities

- `narration-experiments`: 单音色小说朗读的语料身份、受控策略对照、试听决策、长篇验证和逐模型结论。

### Modified Capabilities

无。当前 OpenSpec 主规格目录没有已登记能力；不改动其他在途变更的契约。

## Impact

- 预期扩展 `xtask/src/perf/` 与开发专用模型探针，复用构建收据、进程控制和音频资产校验；现有性能基准协议继续独立。
- 涉及 `talechime-core` 组段/接续、各适配器实验入口及相关无模型夹具；仅在实验需要时增加显式开发路径，不改模型权重或无关推理代码。
- 参考 `docs/records/voice-drift/`、`docs/records/asr/guzhenren-readback-acceptance-2026-10-09.md` 和 `docs/performance-harness.md`，结果汇总到 `docs/records/voice-drift/`。
- TRNovel 仅为本地语料来源，不引入业务类型或依赖，不修改其正文、配置或阅读进度。正文、转写、用户音频和完整本地清单只保存在 Git 忽略目录。
- 不增加默认运行时依赖，不新增模型、不发布或部署，不保证所有模型通过听感验收。
