## Context

官方 Misaki 先规范化数字，再将中文与英文片段分别转音素并拼接；英文空实现会丢词。当前原生前端对任意 ASCII 字母直接失败。

## Goals / Non-Goals

首期覆盖英语单词、缩写和中英数字混排，保持同一声音和源范围；不声称支持其他语言或提供读音编辑 UI。无法处理的内容必须失败，不静默省略。

## Decisions

采用固定版本的 loqui-g2p 离线英文词典与神经词外回退，提升 Rust 要求至依赖所需版本；初始化共享只读实例，检查空输出和未知标记。按官方顺序先中文数字规范化，再拆分英文片段；中文依旧使用原前端，g2pW 在中文片段上预测。保持字词和数字边界以避免预算切分改变读法。第三方许可证与构建大小须单独核验。音素及实际语音质量以官方对照和真实模型测试为准，未听验不宣称听感通过。

## Risks / Trade-offs

英文自动读法和缩写存在歧义，专名需未来人工读音能力；英文切片改变上下文可能影响断句和发音；跨语言表现依赖模型，不等于其他语言支持。宿主文本规范化可能静默删除内容，需宿主独立修复并验证。
