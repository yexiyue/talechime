## ADDED Requirements

### Requirement: Kokoro 中英文混读

系统 SHALL 对包含中文、英文和数字的文本执行离线混合转音素，保留输入原文及原始 UTF-8 范围，使用用户选择的同一声音合成。

#### Scenario: 中英型号混排
- **WHEN** 输入包含中文、英文单词、缩写或字母数字型号
- **THEN** 中文及英文均生成可用音素，数字按确定的规范化规则处理，不因英文字母直接失败

#### Scenario: 上下文多音字
- **WHEN** 使用 g2pW 变体且输入包含中英文
- **THEN** 中文片段仍进行上下文多音字预测

#### Scenario: 无法处理的文字
- **WHEN** 输入包含无法生成有效音素的内容
- **THEN** 返回错误，不静默忽略该内容或报告成功

#### Scenario: 长文切分
- **WHEN** 音素预算导致输入分段
- **THEN** 原始 UTF-8 范围连续完整且不在英文词或数字表达式内部切断
