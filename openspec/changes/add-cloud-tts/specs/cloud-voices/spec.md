# Spec Delta

## Purpose

让宿主发现 Fish 云端音色并使用本地参考录音或远端持久克隆，同时保留各自的身份和生命周期。

## ADDED Requirements

### Requirement: 云音色发现
客户端 SHALL 支持分页检索公开及账户自有音色，并按服务支持的名称、标签和语言过滤；结果 SHALL 保留远端标识和可用状态等返回元数据。

#### Scenario: 公开音色分页
- **WHEN** 宿主请求指定语言的公开音色页面
- **THEN** 返回该页面的远端音色及分页信息，不将其保存为本地参考资产

### Requirement: 即时参考克隆
客户端 SHALL 接受调用方提供的参考音频和转写作为单次合成输入，并使用服务要求的二进制编码；不得隐式创建远端持久音色。

#### Scenario: 使用本地参考录音
- **WHEN** 宿主提供本地音色的录音和转写并请求即时克隆
- **THEN** 合成请求携带对应样本且不创建持久远端音色

### Requirement: 持久克隆生命周期
客户端 SHALL 仅在调用方显式请求时上传样本创建远端音色，并返回远端 ID 和服务报告的状态；宿主 SHALL 能按 ID 查询状态。

#### Scenario: 创建未完成
- **WHEN** 远端创建返回尚未可用的状态
- **THEN** 客户端返回该状态和 ID，不宣称音色已可合成

#### Scenario: 创建结果未知
- **WHEN** 创建请求发送后连接中断且结果未知
- **THEN** 客户端报告结果不确定且不自动重建

### Requirement: 本地与远端身份隔离
远端音色引用 SHALL 保留 provider 与远端 ID；客户端 MUST NOT 将其作为含参考 WAV 的本地资产导出或在本地资产删除时隐式删除远端音色。

#### Scenario: 远端音色不可用
- **WHEN** 已保存的远端 ID 被删除或无权访问
- **THEN** 请求返回明确错误，不替换为其他音色
