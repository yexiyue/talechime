# Spec Delta

## Purpose

为 Rust 宿主提供可独立依赖的云端语音合成能力，并明确请求、音频流、失败和费用边界。

## ADDED Requirements

### Requirement: 独立云端合成
云合成 crate SHALL 独立于本地模型、播放设备及宿主业务类型，接受文本、明确的 provider 和模型、音色来源及输出格式，返回音频流和格式信息。

#### Scenario: 独立使用 Fish 合成
- **WHEN** 宿主使用有效的 Fish 凭据、明确模型和音色请求合成
- **THEN** 宿主可以不加载本地模型或播放器而消费音频流

### Requirement: 模型和费用选择
Fish 请求 SHALL 显式选择受支持的模型；未知或缺失模型 MUST 在发送前失败，不得自动切换到其他模型。

#### Scenario: 错误模型不会回退
- **WHEN** 调用方指定未知模型或未指定模型
- **THEN** 请求失败且不向服务端发送合成请求

### Requirement: 流完成和取消
流 SHALL 有界消费并区分正常完成、失败和取消；中途断开、空输出或取消 MUST NOT 报告成功。取消或丢弃流 SHALL 释放本地网络资源，不保证撤销远端计算或费用。

#### Scenario: 音频传输中断
- **WHEN** 响应流在完成之前中断
- **THEN** 消费者收到失败而非成功完成

#### Scenario: 消费者取消
- **WHEN** 消费者取消或丢弃活动流
- **THEN** 客户端释放本地响应资源，不声称远端未处理请求

### Requirement: 安全错误与重试
客户端 SHALL 区分认证、限流、服务响应和传输错误，并保留可能已处理请求的未知结果；默认不得自动重试有副作用或可能计费的请求。凭据及正文、参考音频 MUST NOT 出现在默认日志或错误文本中。

#### Scenario: 响应前连接中断
- **WHEN** 合成请求发送后连接中断且服务端结果未知
- **THEN** 返回不确定结果且不自动重复发送
