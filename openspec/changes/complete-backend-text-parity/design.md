## Goals / Non-Goals

## Decisions

先迁移 Kokoro 规范化到本地后端，保持现有章节行为；独立复现 Qwen 官方自动语言前缀和 OmniVoice 自动语言语义；按上游固定版本核实 IndexTTS 文本规范化、日/西/阿前端、读音与语速，以及 CosyVoice 跨语言路径；MOSS/VoxCPM 检查实际支持范围和覆盖。使用官方行为对照及真实设备语音验证，不把未验证的能力标记为完成。调用边界、恢复身份、资源许可和输入大小均须明确。

## Risks / Trade-offs

日语前端按固定官方推理默认 `g2p_ratio=0` 对齐：保留原字，以 UniDic 分词边界插入空格。固定上游 NeMo 包装器不对日语执行 TN，不另外展开日语数字日期。先对齐 fugashi + unidic-lite 参考环境和 Rust 分词器的词典与边界，资源缺失明确报错；尚未通过日语对照及真实音频前不宣称日语可用。

官方可选组件、许可证、模型资源、运行环境和算子可能影响实现；不通过删除未知文本、虚假能力目录或忽略失败来宣称兼容。跨平台与人工听感分别记录。
