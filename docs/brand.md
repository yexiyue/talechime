# Talechime · 叙铃

**中文标语：让故事响起来。** 英文标语：**Let stories ring.**

Tale 是故事，Chime 是铃声；中文“叙铃”把叙述与声音连接起来。定位是可被阅读器复用的本地语音与长文播放基础，不将尚未实现的角色分析或多角色播放作为当前卖点。

## 品牌标识

书页折成的小铜铃是核心标识：象牙白纸页代表原文，青绿色声孔代表音频，珊瑚色铃舌代表故事被唤醒。它与 CastGlean 的纸页猫头鹰保持文学气质上的关联，但使用独立形状和色彩。

![品牌标识](../assets/brand/mark.png)

| 颜色 | 色值 | 用途 |
| --- | --- | --- |
| 墨蓝 | `#172B3A` | 标题与文字 |
| 青绿 | `#277C78` | 声音与交互强调 |
| 暖铜 | `#D78B58` | 铃体与品牌点缀 |
| 纸白 | `#F5EEE2` | 背景与纸页 |

## 资产

- `assets/brand/mark.png`：透明背景品牌标识，可用作项目头像。
- `assets/brand/readme-cover.png`：宽幅 README 封面与社交展示。
- `assets/brand/generation.json`：生成提示词、日期、工具和文件记录。

最终资产通过 Codex 内置 image_gen 生成，透明图保留 alpha，封面根据标识作为参考生成。原始提示词见 generation.json。当前交付为 PNG 栅格图，不宣称是可编辑矢量源文件。
