## 构建与安装分开

源配方以固定原始输入经 Rust 导入，已有独立 PyTorch 原始字节对照：Kokoro 599 项、
CosyVoice3 HiFT 246 项、IndexTTS 2,707 项，记录见同目录核验文档。维护方可明确运行
被忽略的准备测试并设置 `TALECHIME_BUILD_NATIVE_SOURCE=1` 来选择源配方；成品配方
不读取该开发选择。所有模型权重与实际运行输出都在 Git 之外。

成品路径仍经过计划指纹、缓存摘要、磁盘预算、准备租约、完整输出/标记校验及原子发布。
v2 组件缓存可按内容摘要复用；v3 放在新目录，旧资源目录不删除。文件复制/硬链接展示
校验阶段，不虚构“转换中”或转换网速。匿名分发通过不自动证明模型数值门禁、音色设计、
桌面播放器或其他平台通过，也不代表发布了 SDK 或应用版本。
