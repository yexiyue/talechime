# Fish 云端合成验证（2026-11-11）

环境：Windows，本工作区 `talechime-cloud-tts` 开发版本，Fish API `s2.1-pro-free`，中文短句“你好，欢迎使用语音合成。”，服务端公开音色（未保存音色 ID）。音频仅保存于本机临时目录，未纳入仓库。

- 使用系统代理的 PowerShell 查询公开中文音色成功，返回一条记录；通过 crate 的 `list_voices` 示例设置 `HTTPS_PROXY` 后也查询成功，返回一条记录，服务报告 total 为 1000（不推断其是否精确）。
- crate 首次直接连接超时并返回 `OutcomeUnknown`；同机 curl 直连超时。系统代理未绕过该域名，设置 `HTTPS_PROXY` 指向系统代理后，显式再次请求成功。首次请求是否到达服务端及计费结果未知，不能断定没有费用。
- 示例的第二次请求含构建/启动的端到端耗时约 3.12 秒；仅一次，不能作为性能基准或 TTFA 结论。
- 响应 47,228 字节；ffprobe 检出 MP3、44.1 kHz、单声道、约 2.95 秒。未人工试听，未验证发音、文本完整性、音色、信号质量或计费账单。
- 即时克隆：参考为 Windows Microsoft Huihui Desktop 合成的中文样本，22.50 秒、22.05 kHz 单声道 WAV，附合成文本；通过 crate 的 MessagePack 请求、`s2.1-pro-free` 与代理完成，响应 37,615 字节、耗时约 4.54 秒；ffprobe 检出 44.1 kHz 单声道 MP3、约 2.35 秒。未试听，不能评价相似度或发音。
- 持久克隆：以同一合成样本提交私有模型创建，两次均返回 HTTP 403，未得到远端 ID。第一次错误类型将 401 与 403 合并；修正区分后第二次确认是 403。另用 PowerShell multipart 请求读取服务端原因，服务报告 API 音色创建限额为 0/0，并提示充值提高限额；本次未充值。创建成功、状态查询及远端音色复用均未通过真实服务验证。
- 不同网络/操作系统、长文本及中断恢复均未实测；未核对账单，费用未知。真实用户或其他授权音色的质量和人工试听均未验证，本次结果不能替代这些验收。

## 同日代码审查补充

修正音频 body 中断被归为无效响应的问题：现在返回 `Transport`，保持 Failed 终态并释放响应；空输出和超限仍为 `InvalidResponse`。本地截断 HTTP 回归验证错误分类，不新增真实服务验收。取消、完成和失败共用终态资源释放方法。持久克隆探针在创建前独占打开 ID 文件，避免目录不可写时先创建远端音色或覆盖已有 ID；写盘仍可能失败，不能保证远端回滚。
