# OmniVoice CPU 注意力布局优化（2026-10-23）

本轮仅验证 CPU attention 的布局/BLAS 调用路径，不改变采样、精度、依赖或公共 API。
基线 `8e57393` 的运行时与 `3b6bb0d` 相同，macOS 已默认启用 Accelerate。
机器为 M4 Pro / 12 CPU 核 / 24 GiB / macOS 26.6.2；CPU stage0 与 decoder 均 F32。
Candle 固定 `2266099d92265112ecc0d56ecee1761e3cc2ac00`，线程配置 Rayon/VecLib/OMP 各 8。

## 候选和数值边界

固定 CPU Accelerate matmul 接受矩阵末两维的转置 stride。原 attention 仍在
`K.transpose(2,3)` 后调用 contiguous，实体复制后交给 BLAS；候选让 BLAS 直接读转置。
该改动不仅省复制，还切换 BLAS 的 transpose 路由，收益不能全部归因给拷贝字节。

离线 `cpu_attention_probe` 采用实际短句形状 Q `[2,16,157,128]`、KV `[2,8,157,128]`，
V 保持投影后的转置视图，有加性 mask。包含重复 KV、分配、scale/softmax 与完整 context。
激活为合成数据，不能代替真实模型归因；首版正弦数据后补充确定性伪随机数据。
每个进程内原版、转置视图、分组 GQA、CPU Flash 按 ABCDDCBA 交错，
每组 3 次预热 + 20 次热测。CPU 同步执行，结果为墙钟，不称为 GPU kernel 时间。

| 候选 | 说明与数值判断 |
| --- | --- |
| 转置 K 视图 | 实际 head_dim=128 的合成完整输出零 bit 差异，继续真实模型验收 |
| 分组 GQA | Q 的重复头合并进 M，减少 KV 复制/BLAS 调用；实际形状探针输出一致，暂不与首项叠加进入生产 |
| Candle CPU Flash | batch 2 + 显式 mask 不支持，按 batch 拆调用后拼接；随机输入 588829/643072 元素位模式不同、max_abs 5.59e-8，且本例较慢，不接入生产 |

首个宽泛 CPU 特化在随机测试的 batch=1、seq=7、head_dim=8 上出现位差。
因此撤回泛化范围，仅对 CPU F32 + Accelerate + 连续 K + head_dim=128 启用；
其余设备、dtype、维度、非连续 K 保留原 contiguous 路由。没有放宽数值门槛。
这不是证明任意 BLAS 形状等价，也不从有限测试推断所有 CPU/系统版本都逐位相同。

普通测试比较独立物化 K 的原公式，覆盖 batch 1/2、seq 1/7/33/157、dim 8/128、
有无 mask、非连续 K 和重复调用。24 项 CPU、35 项 Metal 单元测试通过；
Metal all-targets Clippy / rustdoc（lib+examples）warnings denied 通过，不下载模型。

## 真实模型输出

短文本与长文本原/候选均单独执行完整生成。所有 codes dump 逐字节相同，覆盖参考
预热与所有正文生成；短文本 4 个、长文本 24 个整段/逐段 F32、PCM16 WAV 均逐字节一致。
这也检查了样本数和采样率，而非只比较 seed 或最终 PCM16。另有正式整链 12 个
Rust 热轮的完整 F32 WAV 哈希全部相同：
`2de9f6fb2688b651a33a36470cace6acf3c1e8126d17feb5094c18691d1a9b5c`。
本轮未做新增试听/ASR，不从 Rust 新旧一致推断与官方内容/音质等价。

保留限定范围的转置 K 视图：组件和整链均有可重复收益，改动只有私有分支，未增加缓存
或实验开关。非 128 head dimension 的已知数值差异通过回退规避，不推广到其他模型/AMD。

## 投影/MLP 权重布局：仅离线候选

使用真实第 0 层的七个权重，激活为确定性合成 F32（未捕获真实隐藏态），比较
`X × W.t()` 与加载时物化 `W.t()` 后的同一次 matmul。预转置加载成本单列，
不藏在 forward 计时中。最终探针三个独立进程内 ABBA、每组 3 预热 + 20 热轮，
rows=314；全部输出逐位一致，未观察到编译活动。以下是三个进程均值的均值，单位 µs。

本轮不改生产权重布局，不把组件收益乘层数，也不把它算进已报告的整链改善。
后续若继续此候选，需要选择性路由、短形状回退、加载/内存成本和完整生成验收，
而非让所有 CPU linear 默认换布局。
