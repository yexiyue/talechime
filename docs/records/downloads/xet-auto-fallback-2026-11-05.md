# Xet 自动选择、HTTP 回退与有效断点

2026-11-05，macOS。hf-hub fork 固定 revision `52fc24bf0075c4fcf159a03b3de56f5c41121782`，TaleChime 不再 vendor；SDK 默认采用 Auto。

## API 与模块

`DownloadOptions` 分离连接策略和凭据/缓存配置：默认 `connections: 2`、`DownloadTransport::Auto`；还可选 Http 或 Xet。Auto 读取固定文件元数据，支持 Xet 时优先使用；不支持或网络失败时尝试一次 HTTP 回退。取消、Hub 鉴权拒绝、磁盘失败与内容校验失败不会被当成普通网络重试；Xet 专用认证不可用时可尝试同一文件的 HTTP 受保护链接。

fork 内的 HTTP、Xet 数据源实现同一范围接口，输出通用的“绝对偏移 + 数据块”；Xet 原始偏移相对请求起点，适配器负责转换。调度、覆盖计算、断点持久化分别封装，未暴露到 Tauri IPC。SDK 仍输出已确认的文件字节，宿主负责速率/ETA 与下载任务。

Xet 使用官方乱序流及其自适应并发，不把文件切成大量独立的小 Xet 请求。断点仍为 4 MiB，只有每片连续有效前缀进入持久化状态，分散且未接齐的片段仅在内存中保留；暂停后可重新请求。HTTP 和 Xet 可以相互继续这些有效断点，不按稀疏文件长度判断完成。

初始化 Xet 最多 15 秒；取得范围执行槽后，首个片段最多 30 秒，随后片段读取最多 90 秒。等待执行槽、最终文件哈希不计入此预算。最终长度和可用 SHA-256 验证通过才发布缓存及引擎文件。

## 真实公网小文件对照

公开文件 `sentence-transformers/all-MiniLM-L6-v2`，固定 revision `1110a243fdf4706b3f48f1d95db1a4f5529b4d41` 的 `model.safetensors`，90,868,376 字节。每轮独立缓存，完整 SHA-256 验证通过。

| 入口 | 首轮 HTTP | 当前 Auto，实际选择 Xet |
| --- | ---: | ---: |
| 官方 | 17.832 秒 | 12.383 秒 |
| HF-Mirror | 19.430 秒 | 14.800 秒 |

这是少量串行样本，并非随机配对基准；另外 HTTP 样本为 15.184 与 31.192 秒，不能承诺稳定倍速。镜像入口返回绝对 308 到官方，实际仍使用官方 CAS/CDN，不能宣称镜像独立分发或带来额外加速。

一次强制 Xet 的镜像样本接收部分数据后失败，不计作成功测速；Auto 在实际传输失败时也会回退，而非仅检查起始能力。受控入口转发真实元数据、屏蔽 Xet token 接口的测试中，日志明确记录 HTTP 回退，90,868,376 真实字节在 25.091 秒完成，完整哈希正确。受控服务器和临时数据已清理。

真实 Xet 暂停在 23,759,512 字节，检查点保存健康；新建客户端继续，完整文件哈希正确，总过程约 19.972 秒。

## MOSS 生产权重的有界进度验证

通过应用使用的 `Downloads::ensure` / `FileProgressBridge` 通道下载固定 MOSS Realtime revision `75682787d8e2fcc73faca37ba2931453ca9c4022` 的 4,663,931,664 字节权重，独立临时缓存、60 秒 / 8 MiB 字节预算，不加载模型。

2.48 秒收到零字节初始化；10.19 秒收到 67,093,117 个已确认文件字节，随后按预算停止，没有发生 HTTP 回退。Xet 一个片段可超过预算，属于观察而不是整文件完成证据。没有将网络压缩字节冒充文件进度，也没有改动用户共享缓存。

最终固定版本的 CastGlean 真实 Channel 验证另设门槛：当前文件必须为 `model.safetensors`、累计字节超过 8 MiB 且速率/ETA 均为正，避免小型配置文件就提前通过。10.48 秒内观察到 67,095,785 个累计文件字节、约 13.4 MB/s 和 872 秒剩余时间估算；达到门槛即停止，隔离缓存已清理。速率与 ETA 为宿主当时的窗口估算，不是整模型速度或完成时间承诺。
